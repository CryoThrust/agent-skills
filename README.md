# Agent Skills

A collection of skills for AI agents.

## Skills

### architecture-diagram

Generate professional HTML architecture diagrams with collision-free layout, clear connections, and unified styling.

**Install:**
```bash
npx skills add https://github.com/CryoThrust/agent-skills --skill architecture-diagram
```

**Features:**
- No component collisions
- Clear connection lines
- Unified styling
- Responsive design
- Support for various architecture types (microservice, business, technology, deployment, data)
