## Group Internal Layout

### 分组内边距规则

| 位置 | 最小值 | 说明 |
|------|--------|------|
| 左右内边距 | 16px | 组件到分组左右边框 |
| 顶部内边距 | 26px | 包含标签空间（标签高约10px + 间距） |
| 底部内边距 | 16px | 最后一个组件到分组底部 |

### 分组尺寸计算

**核心公式**：

```
分组宽度 = max(组件宽度) + 32px（左右内边距各16px）
分组高度 = 组件高度之和 + (组件数-1)×8px + 42px（顶部26px + 底部16px）
```

**组件定位规则**：

```
Component.left = Group.left + 16
Component[0].top = Group.top + 26
Component[i].top = Component[i-1].bottom + 8  (i > 0)
```

**底部内边距验证（必须执行！）**：

```
底部内边距 = Group.bottom - 最后组件.bottom

✅ 正确：底部内边距 >= 16px
❌ 错误：底部内边距 < 16px（组件贴边）
```

**快速验证公式**：

```
分组高度必须满足：
  Group.height = 最后组件.bottom - Group.top + 底部内边距
  底部内边距 >= 16px

计算示例：
  最后组件 bottom = 394 + 36 = 430
  Group.top = 280
  最小分组高度 = 430 - 280 + 16 = 166px
  实际分组高度 = 168px ✓ (166 < 168)
```

**常见错误**：

```
❌ 分组高度 = 所有组件高度 + 组件间距 + 顶部内边距
   （忘记加底部16px）

✅ 分组高度 = 所有组件高度 + 组件间距 + 顶部26px + 底部16px
```

### 错误示例

```
❌ 错误：组件底部贴边
  ┌─────────────────────┐
  │ [标签]              │
  │  ┌───────────────┐  │
  │  │ Component 1   │  │
  │  └───────────────┘  │
  │  ┌───────────────┐  │ ← 组件底部与分组底部齐平
  │  │ Component 2   │  │
  └─────────────────────┘

✅ 正确：底部有16px内边距
  ┌─────────────────────┐
  │ [标签]              │
  │  ┌───────────────┐  │
  │  │ Component 1   │  │
  │  └───────────────┘  │
  │  ┌───────────────┐  │
  │  │ Component 2   │  │
  │  └───────────────┘  │
  │                     │ ← 16px 空白
  └─────────────────────┘
```

## Collision Detection

```
right = left + width
bottom = top + height

避免碰撞：A.right < B.left OR A.left > B.right
         A.bottom < B.top OR A.top > B.bottom
```

**边界检查**：
- 无信息卡片：最大 group.right < 1360px
- 有信息卡片：最大 group.right < 1140px（预留右侧 260px）

## Connection Rules

### 锚点（连线必须连接到组件边缘，不能是中心）

```
左中: (left, top + height/2)           -- 组件左边框中点
右中: (left + width, top + height/2)   -- 组件右边框中点
上中: (left + width/2, top)            -- 组件上边框中点
下中: (left + width/2, top + height)   -- 组件下边框中点
```

**示例**：组件 A (left=100, top=50, width=120, height=40)
- 右中锚点坐标：(220, 70) = (100+120, 50+20)
- 下中锚点坐标：(160, 90) = (100+60, 50+40)

### 路径规则

**禁止斜线！只能使用水平线 + 垂直线！**

| 类型 | 用法 | 起点锚点 | 终点锚点 | 代码 |
|------|------|---------|---------|------|
| 水平直线 | A在B左边，同行 | A右中 | B左中 | `<line x1="A.right" y1="Y" x2="B.left" y2="Y" />` |
| 垂直直线 | A在B上边，同列 | A下中 | B上中 | `<line x1="X" y1="A.bottom" x2="X" y2="B.top" />` |
| 折线 | 跨行跨列 | A右中/下中 | B左中/上中 | `<path d="M 起点 L 拐点1 L 拐点2 L 终点" />` |

**折线路径构造**：
```
A右中(X1,Y1) → 水平向右 → (X2,Y1) → 垂直 → (X2,Y2) → 水平向左 → B左中(X3,Y2)
```

### 连线最小长度

- **最小线段长度：40px**
- 确保虚线至少显示 2-3 个周期
- 如果组件间距不足，调整组件位置或使用折线绕行

### 连线约束
- **禁止斜线**：x1≠x2 且 y1≠y2 是错误的
- 起点/终点必须是组件边缘锚点
- 拐点坐标必须是 10 的倍数
- **连线不能穿过组件内部**
- 平行连线间距 >= 10px

### 连线绕行规则

**连线必须绕过所有组件，不能穿过任何 box！**

#### 检测方法

```
检查 A→C 连线是否穿过 B：
1. 水平连线：检查 Y 坐标是否在 B.top ~ B.bottom 范围内
2. 垂直连线：检查 X 坐标是否在 B.left ~ B.right 范围内
3. 如果穿过，必须使用折线绕行
```

#### 绕行策略

| 情况 | 绕行方式 | 示例 |
|------|---------|------|
| B 在 A、C 之间 | 从 B 上方或下方绕过 | A→上→绕过B→下→C |
| B 在连线路径上 | 从 B 左侧或右侧绕过 | A→左→绕过B→右→C |
| 多个障碍物 | 选择最短绕行路径 | 计算各路径长度，选最短 |

#### 绕行间距

- 连线与组件边缘至少保持 **20px** 距离
- 拐点位置必须是 **10 的倍数**

```
❌ 错误：连线穿过组件
    [A] ────────────────→ [C]
              [B]        （连线穿过 B）

✅ 正确：从上方绕过
    [A] ──┐
          │
          ├────────────→ [C]
          │
    [B] ──┘              （连线从 B 上方绕过）

✅ 正确：从下方绕过
    [A] ──┐
    [B]   │
          ├────────────→ [C]
          │
          ┘              （连线从 B 下方绕过）
```

## Legend Rules

- 位置：与标题同高（legend.top = title.top，默认 top:22px），横向单行排列
- 容器宽度：520-620px（确保一行放 5 类连线）
- 必须添加 `pointer-events:none` 避免阻挡连线悬停
- 显示所有连线类型（至少 5 类：主流程/数据流/依赖/控制/事件）
- 每项使用虚线 + 箭头：`stroke-dasharray="4,3" + marker-end`
- 颜色必须与连线 stroke 一致
- 标签根据架构类型适配（见 style-guide.md）

**图例项布局**：
```
每项宽度约 100px（line 24px + gap 6px + text 70px）
5 类总宽度约 500px + 间距 = 520-620px
```

## Connection Text Label Rules

### 基本定位规则

**文字必须紧贴连线！最大偏移 15px！**

| 连线类型 | 默认位置 | X 坐标 | Y 坐标 | 对齐方式 |
|----------|----------|--------|--------|----------|
| 水平连线 | 连线上方 | (x1+x2)/2 | y1 - 5 | text-anchor:middle |
| 水平连线（上方遮挡）| 连线下方 | (x1+x2)/2 | y1 + 12 | text-anchor:middle |
| 垂直连线 | 连线右侧 | x1 + 8 | (y1+y2)/2 | dominant-baseline:middle |
| 垂直连线（右侧遮挡）| 连线左侧 | x1 - 8 | (y1+y2)/2 | text-anchor:end, dominant-baseline:middle |

### 文字重叠处理策略

**场景 1：多条水平连线距离 < 30px**

```
连线A (y=140): y = 140 - 5 = 135  (上移)
连线B (y=150): y = 150 + 12 = 162 (下移，避免重叠)
连线C (y=160): y = 160 - 5 = 155  (上移，与B错开)
```

**场景 2：多条垂直连线距离 < 30px**

```
连线A (x=300): x = 300 + 8 = 308   (右侧)
连线B (x=310): x = 310 - 8 = 302, text-anchor:end (左侧)
连线C (x=320): x = 320 + 8 = 328   (右侧，与B错开)
```

**场景 3：交叉连线**

```
当水平连线与垂直连线交叉时：
- 水平连线文字优先放在上方
- 垂直连线文字优先放在交叉点外侧
- 避免在交叉点附近放置文字
```

### 文字漂移检测

**检查项**：
```
水平连线文字：
  |实际Y - 连线Y| <= 15px

垂直连线文字：
  |实际X - 连线X| <= 15px
```

**错误示例**：
```
❌ 连线在 y=200，文字在 y=180（漂移 20px）
❌ 连线在 x=300，文字在 x=330（漂移 30px）
```

**正确示例**：
```
✅ 连线在 y=200，文字在 y=195（偏移 5px）
✅ 连线在 x=300，文字在 x=308（偏移 8px）
```

### 文字长度限制

| 语言类型 | 最大字符数 | 计算 |
|----------|------------|------|
| 纯英文 | 8 字符 | 8×6 = 48px 宽度 |
| 纯中文 | 6 字符 | 6×8 = 48px 宽度 |
| 混合 | 总宽度 < 50px | 英文×6 + 中文×8 |

**超长处理**：使用缩写或省略（如 "HTTP/HTTPS" → "HTTP"）

## Canvas Sizing Rules

### 画布高度自适应

```
画布高度 = max(所有分组.bottom, 基础设施层.bottom) + 80px

取整规则：向上取整到最近的 100px
```

**示例**：
| 最大 bottom | 计算高度 | 实际高度 |
|-------------|----------|----------|
| 620px | 620 + 80 = 700 | 700px |
| 720px | 720 + 80 = 800 | 800px |
| 820px | 820 + 80 = 900 | 900px |
| 920px | 920 + 80 = 1000 | 1000px |
| 1020px | 1020 + 80 = 1100 | 1100px |

### 画布宽度规则

- **默认宽度**：1440px（固定）
- **最大组件 right**：< 1140px（预留右侧 260px 信息区）
- **特殊情况**：组件过多时可考虑横向布局，但宽度不超过 1600px

### viewBox 设置

```html
<!-- 根据实际高度调整 viewBox -->
<svg viewBox="0 0 1440 {实际高度}">
```

```html
<!-- canvas 高度也要同步修改 -->
<div class="canvas" style="height: {实际高度}px">
```
