## Group Internal Layout

### 分组内边距规则

| 位置 | 最小值 | 说明 |
|------|--------|------|
| 左右内边距 | 16px | 组件到分组左右边框 |
| 顶部内边距 | 26px | 包含标签空间（标签高约10px + 间距） |
| 底部内边距 | 16px | 最后一个组件到分组底部 |

### 分组尺寸计算

```
分组宽度 = max(组件宽度) + 32px（左右内边距各16px）
分组高度 = 组件高度之和 + (组件数-1)×8px + 42px（顶部26px + 底部16px）

组件定位：
  Component.left = Group.left + 16
  Component[0].top = Group.top + 26
  Component[1].top = Component[0].bottom + 8
  ...
  最后一个组件.bottom + 16 = Group.bottom

验证公式：
  Group.height = Component[-1].bottom - Group.top + 16
```

### 错误示例

```
❌ 错误：组件底部贴边
  ┌─────────────────────┐
  │ [标签]              │
  │  ┌───────────────┐  │
  │  │ Component 1   │  │
  │  └───────────────┘  │
  │  ┌───────────────┐  │ ← 组件底部与分组底部齐平
  │  │ Component 2   │  │
  └─────────────────────┘

✅ 正确：底部有16px内边距
  ┌─────────────────────┐
  │ [标签]              │
  │  ┌───────────────┐  │
  │  │ Component 1   │  │
  │  └───────────────┘  │
  │  ┌───────────────┐  │
  │  │ Component 2   │  │
  │  └───────────────┘  │
  │                     │ ← 16px 空白
  └─────────────────────┘
```

## Collision Detection

```
right = left + width
bottom = top + height

避免碰撞：A.right < B.left OR A.left > B.right
         A.bottom < B.top OR A.top > B.bottom
```

**边界检查：** 最大 group.right < 1140px（预留右侧信息区）

## Connection Rules

### 锚点（连线必须连接到组件边缘，不能是中心）

```
左中: (left, top + height/2)           -- 组件左边框中点
右中: (left + width, top + height/2)   -- 组件右边框中点
上中: (left + width/2, top)            -- 组件上边框中点
下中: (left + width/2, top + height)   -- 组件下边框中点
```

**示例**：组件 A (left=100, top=50, width=120, height=40)
- 右中锚点坐标：(220, 70) = (100+120, 50+20)
- 下中锚点坐标：(160, 90) = (100+60, 50+40)

### 路径规则

**禁止斜线！只能使用水平线 + 垂直线！**

| 类型 | 用法 | 起点锚点 | 终点锚点 | 代码 |
|------|------|---------|---------|------|
| 水平直线 | A在B左边，同行 | A右中 | B左中 | `<line x1="A.right" y1="Y" x2="B.left" y2="Y" />` |
| 垂直直线 | A在B上边，同列 | A下中 | B上中 | `<line x1="X" y1="A.bottom" x2="X" y2="B.top" />` |
| 折线 | 跨行跨列 | A右中/下中 | B左中/上中 | `<path d="M 起点 L 拐点1 L 拐点2 L 终点" />` |

**折线路径构造**：
```
A右中(X1,Y1) → 水平向右 → (X2,Y1) → 垂直 → (X2,Y2) → 水平向左 → B左中(X3,Y2)
```

### 连线最小长度

- **最小线段长度：40px**
- 确保虚线至少显示 2-3 个周期
- 如果组件间距不足，调整组件位置或使用折线绕行

### 连线约束
- **禁止斜线**：x1≠x2 且 y1≠y2 是错误的
- 起点/终点必须是组件边缘锚点
- 拐点坐标必须是 10 的倍数
- **连线不能穿过组件内部**
- 平行连线间距 >= 10px

### 连线绕行规则

**连线必须绕过所有组件，不能穿过任何 box！**

#### 检测方法

```
检查 A→C 连线是否穿过 B：
1. 水平连线：检查 Y 坐标是否在 B.top ~ B.bottom 范围内
2. 垂直连线：检查 X 坐标是否在 B.left ~ B.right 范围内
3. 如果穿过，必须使用折线绕行
```

#### 绕行策略

| 情况 | 绕行方式 | 示例 |
|------|---------|------|
| B 在 A、C 之间 | 从 B 上方或下方绕过 | A→上→绕过B→下→C |
| B 在连线路径上 | 从 B 左侧或右侧绕过 | A→左→绕过B→右→C |
| 多个障碍物 | 选择最短绕行路径 | 计算各路径长度，选最短 |

#### 绕行间距

- 连线与组件边缘至少保持 **20px** 距离
- 拐点位置必须是 **10 的倍数**

```
❌ 错误：连线穿过组件
    [A] ────────────────→ [C]
              [B]        （连线穿过 B）

✅ 正确：从上方绕过
    [A] ──┐
          │
          ├────────────→ [C]
          │
    [B] ──┘              （连线从 B 上方绕过）

✅ 正确：从下方绕过
    [A] ──┐
    [B]   │
          ├────────────→ [C]
          │
          ┘              （连线从 B 下方绕过）
```

## Legend Rules

- 位置：标题右侧（top:28px, right:40px）
- 必须添加 `pointer-events:none` 避免阻挡连线悬停
- 只显示实际使用的连线类型
- 颜色必须与连线 stroke 一致
- 标签根据架构类型适配（见 style-guide.md）
